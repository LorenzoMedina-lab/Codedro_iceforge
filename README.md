# Codedro_iceforge
Implementación de clases y Programación orientada a Objetos 
README: Iceforge - Sistema de Supervivencia Ártica📋 Descripción del ProyectoIceforge es un simulador de supervivencia desarrollado en Python bajo el paradigma de Programación Orientada a Objetos (POO). El objetivo del sistema es gestionar los recursos de una base ártica ("Igloo Base") y coordinar las acciones de un equipo de especialistas para sobrevivir al desgaste diario de la tormenta. Arquitectura de Software 
El proyecto está estructurado en tres capas principales para garantizar el bajo acoplamiento y la alta cohesión:entidades.py (Capa de Dominio): Contiene la lógica de los personajes, el manejo de energía y las reglas de estado (Activo/Caído).motor.py (Capa de Control): Orquestador de la simulación. Maneja el paso del tiempo, el flujo del juego y los recursos globales.main.py (Capa de Aplicación): Punto de entrada del sistema. Inicializa el motor y arranca la ejecución.
 Pilares de la POO AplicadosPilarImplementación TécnicaAbstracciónUso de la clase base Entidad(ABC) y métodos abstractos para definir un contrato obligatorio.EncapsulamientoAtributos protegidos (_) y uso de Getters/Setters con decoradores @property para validar datos (ej. evitar energía negativa).HerenciaLos especialistas (Ingeniero, Recolector, Explorador) heredan la lógica base de salud y atributos de la clase Entidad.PolimorfismoEl motor ejecuta las acciones de todo el equipo mediante una sola llamada al método .ejecutar_turno(), independientemente del tipo de especialista.
